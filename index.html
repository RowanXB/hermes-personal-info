Hermes Personal

Hermes Personal is Chengyan Tong’s personal Google Workspace integration for the Hermes assistant. It connects the owner’s Google account to their own Hermes installation using Google OAuth.

Depending on the permissions already granted and the task requested, Hermes can access and process Gmail messages and attachments, Calendar events, Drive files, Docs documents, Sheets spreadsheets, and Contacts. It supports personal tasks such as finding information, summarising content, and managing documents or schedules. Write actions depend on the granted permissions and the owner’s instructions.

This integration is for the owner’s personal use. This website provides information only; it does not offer public sign-up or collect Google credentials.

Google data retrieved for a task may be sent to the model provider or API gateway configured in Hermes. Processing is not necessarily confined to the owner’s computer. Please read the privacy policy and terms of use.

This personal integration is not a Google product or an official website of the Hermes software developer.
